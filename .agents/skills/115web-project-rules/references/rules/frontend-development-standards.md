# 115 Cloud Drive 前端项目规范

## 适用范围

本规则作为 `115 Cloud Drive` 的项目级前端实现约束，适用于：

- 115 Cloud Drive 前端规格文档整理与审查
- 115 Cloud Drive 前端页面、组件、Store、Service、API 适配层设计
- 与当前 Cloud Drive 后端契约直接相关的交互与实现对齐

通用前端规则请优先参考：`references/rules/frontend-general-standards.md`

当以下来源发生冲突时，优先级如下：

1. 当前后端实际接口契约
2. 当前 feature 的 `requirements.md`、`design.md`、`tasks.md`
3. 本规则文档
4. `frontend-general-standards.md`

## 技术栈与基础设施

- **[项目约定]** 前端运行时技术栈以 `Vue 3 + TypeScript + Vite + Pinia + Vue Router` 为准
- **[项目约定]** HTTP 客户端统一基于 `Axios + AbortController` 实现请求与取消语义
- **[项目约定]** 基础组件库采用 `Naive UI`
- **[项目约定]** 样式体系采用 `Tailwind CSS + CSS Variables`
- **[项目约定]** 图标库采用 `Lucide Icons`
- **[项目约定]** 视频播放优先采用 `Video.js`，先复用其内置 HLS/VHS 能力；仅在播放器封装或兼容性确有需要时再补充 `hls.js`
- **[项目约定]** PDF 渲染优先采用 `PDF.js`
- **[项目约定]** 不应无理由引入与现有职责重叠的新基础设施库

## 分层与目录约定

推荐的前端分层如下：

- **[项目约定]** `views/`：页面编排、路由入口、页面级状态绑定
- **[项目约定]** `components/`：可复用 UI 单元，不直接耦合后端协议细节
- **[项目约定]** `stores/`：模块级状态、跨组件共享状态、加载态/错误态/选择态管理
- **[项目约定]** `services/`：横切业务逻辑，如操作双态处理、任务轮询、临时资源重试、快捷键管理
- **[项目约定]** `api/`：HTTP 封装、错误映射、参数组装、枚举归一化
- **[项目约定]** `types/`：跨层共享 DTO、输入模型、联合类型、结果模型
- **[项目约定]** `utils/`：纯函数与映射逻辑，不依赖 Store、Router 或 UI 实例

数据流保持：

- **[项目约定]** `View -> Store -> Service -> API -> Backend`

禁止事项：

- **[项目约定]** 组件中直接散落原始 `Axios` 调用
- **[项目约定]** 在多个组件/Store 中重复声明同一 DTO
- **[项目约定]** 在组件层手写后端枚举数值映射

## 路由、授权与账号上下文

### 115 Cloud Drive 当前授权口径

- **[当前契约]** 前端采用 Cookie-based 会话模型，Cookie 由后端 integration 服务管理和注入 115 API 请求
- **[当前契约]** Cookie-based 仅说明会话承载方式，不代表自动安全；后端必须为会话 Cookie 设置 `HttpOnly`、`Secure`、`SameSite`，并对状态变更请求实施 CSRF 防护
- **[当前契约]** 前端不得读取、写入或覆盖会话 Cookie；若后端 OpenAPI 暴露 CSRF header/token 契约，前端只能在统一 API 层按契约携带，不得自造 token
- **[当前契约]** 前端仅通过 `GET /api/auth/check` 查询登录态，不实现 OAuth、PKCE、授权回调页或账号授权交换
- **[当前契约]** 当前前端为单账号模型，不提供多账号切换，不维护 `currentAccountUid`
- **[项目约定]** 未登录态、Cookie 失效态与功能不可用态由布局容器承载
- **[项目约定]** 鉴权失败时优先保持当前 URL，由布局层决定渲染登录引导或禁用态

### 账号上下文传递

- **[当前契约]** 前端不向 Cloud Drive API 显式传递 `CloudAccountUid`
- **[当前契约]** 账号上下文由后端 integration 服务根据 Cookie 会话解析
- **[项目约定]** 若未来恢复多账号能力，必须先更新 `.kiro/specs/115-cloud-drive-frontend/` 后再修改前端实现

## API 适配层规范

### 项目职责

- **[项目约定]** 所有 Cloud Drive 请求统一通过 API 层封装的 `AxiosInstance` 发起
- **[项目约定]** 对取消请求、临时资源过期、后端错误码和兼容字段的处理统一收口在 API/Service 层
- **[项目约定]** API 层返回的应是前端消费 DTO，而不是后端未经处理的原始响应
- **[项目约定]** 所有枚举归一化、错误码映射、兼容字段处理统一收口在 API 层

### 枚举归一化

- **[项目约定]** 以下业务状态优先在前端以字符串联合类型存在：
  - `CloudDriveAuthorizationFlowType`
  - `CloudDriveDocPreviewDto.renderMode`
  - `CloudDriveVideoPlayDto.status`
  - `CloudDriveJobType`
  - `CloudDriveJobStatus`
- **[项目约定]** 若后端仍返回数值枚举，必须在 API 边界完成双向映射

### 115 Cloud Drive 当前接口口径

- **[当前契约]** 当前前端代理上传流程只使用 `fileApi.upload()`，不使用 `/files/upload/init`
- **[当前契约]** 上传请求必须组装为 `multipart/form-data`
- **[当前契约]** 上传字段名固定为 `file`、`directoryId`、`forceAsync`
- **[当前契约]** `videoApi.getPlay()` 使用 `GET /api/videos/{pickCode}/play`；后端内部按 `docs/115-api-docs.md` 调用 `GET webapi.115.com/files/video?pickcode=...&share_id=0&local=1&format=json`
- **[当前契约]** 显式提交转码任务时使用 `submitTranscode()`，对应 `POST /api/videos/{pickCode}/transcode`
- **[当前契约]** `getSubtitles()` 返回 `ListResult<CloudDriveSubtitleDto>`，消费方必须从 `items` 读取
- **[当前契约]** `clearRecycleBin()` 当前固定返回后台任务 `jobId`

## 状态管理与数据流规范

- **[项目约定]** 至少维护以下 Store：`AuthStore`、`FileStore`、`SearchStore`、`RecycleBinStore`、`UploadStore`、`OfflineStore`、`ShareStore`、`UserCenterStore`、`UIStore`
- **[项目约定]** `UploadStore` 必须对每个上传文件独立建模，分别维护状态、进度与错误信息
- **[项目约定]** `UIStore` 必须维护快捷键作用域相关状态，如 `fileBrowserFocused`、`activeModal`、`keyboardSuspended`
- **[当前契约]** 根目录固定为 `"0"`
- **[当前契约]** `SearchStore` 必须保存 `previousDirectoryId`，用于“返回浏览”恢复目录上下文

## 文件浏览、搜索与文件操作规范

### 文件列表与搜索

- **[项目约定]** 排序结果必须满足“文件夹优先于普通文件”
- **[项目约定]** 无限滚动优先使用 `IntersectionObserver`
- **[项目约定]** 无限滚动请求需要防抖与去重
- **[项目约定]** 缩略图与列表预览使用懒加载与视口优先策略
- **[当前契约]** 当前默认 `queryCapabilities = { serverSort: false, serverFilter: false }`
- **[当前契约]** 当服务端排序/筛选不可用时，仅对当前已加载结果做本地排序/筛选，并明确提示“仅对当前已加载项目生效”
- **[当前契约]** 搜索关键词为空或纯空白时不得发请求，并提示“请输入搜索关键词”
- **[当前契约]** 点击“返回浏览”后，必须恢复到搜索前目录上下文

### 列表预览资源边界

- **[项目约定]** 列表或网格中的图片/视频预览应优先使用缩略图或明确用于列表预览的字段
- **[当前契约]** 不得为列表展示主动请求原图预览、视频播放或其他完整原始资源接口
- **[当前契约]** 缩略图失败只回退为图标或占位图，不阻塞整个列表渲染

### 选择、批量操作与剪贴板

- **[项目约定]** 支持 `Ctrl` 多选与 `Shift` 范围选择
- **[当前契约]** `Ctrl+A` 只选择当前已加载结果；若目录尚未完整加载，需提示“已选择当前已加载项目”
- **[当前契约]** 批量下载必须拆为多个单文件下载顺序执行
- **[当前契约]** 当浏览器阻止连续下载时，必须显式提示用户
- **[当前契约]** 应用内复制/剪切/粘贴只依赖内部剪贴板，不依赖系统剪贴板读写
- **[当前契约]** 空白区域右键菜单中的“粘贴”仅在存在内部剪贴板数据时显示

### 文件操作与回收站

- **[项目约定]** 同步完成的创建、重命名、上传、移动、复制、删除操作在成功后刷新相关视图
- **[当前契约]** 删除前确认文案为“文件将移至回收站”
- **[当前契约]** 彻底删除确认文案为“文件将被永久删除且无法恢复”
- **[当前契约]** 回收站还原同步完成后立即从当前列表移除并提示“文件已还原”
- **[当前契约]** 清空回收站启动时提示“回收站清理已开始”
- **[当前契约]** 手动刷新目录时，必须先调用后端刷新接口，再重置分页并拉取最新列表数据

## 同步/异步双态与后台任务轮询规范

- **[项目约定]** 所有文件操作统一按“同步完成 / 异步受理”双态处理
- **[项目约定]** 同步完成后立即刷新受影响视图并反馈成功状态
- **[项目约定]** 异步受理后由触发该操作的页面或服务调用 `jobsApi.poll(jobId)` 按需轮询，提示“任务已开始”，待任务完成后再刷新视图

### 刷新目标

- **[当前契约]** 异步上传刷新当前目录
- **[当前契约]** 批量移动至少刷新源目录与目标目录
- **[当前契约]** 批量复制至少刷新目标目录
- **[当前契约]** 批量删除刷新当前或源目录
- **[当前契约]** 回收站还原、彻底删除、清空回收站刷新回收站

### 页面内任务展示与轮询

- **[当前契约]** 全局 `Task_Panel` / `JobStore` 不在当前前端迭代范围
- **[当前契约]** 云下载任务仅在云下载页面内展示，由 `OfflineStore` 维护列表、配额、统计与 10 秒刷新
- **[项目约定]** 按需后台任务轮询在任务进入 `completed` 或 `failed` 终态后必须停止
- **[项目约定]** 页面不可见时应暂停或降低页面内自动刷新频率

## 预览与播放规范

### 临时资源恢复策略

- **[项目约定]** 下载、图片预览、文档预览、视频播放等临时资源地址统一按“可能过期”处理
- **[项目约定]** 首次失败自动重新获取最新地址并重试一次
- **[项目约定]** 自动重试仅允许一次
- **[项目约定]** 二次失败后进入可恢复错误态，提供重试、关闭、下载或新窗口打开等恢复入口

### 图片预览

- **[项目约定]** 图片灯箱仅遍历可安全预览的图片集合
- **[当前契约]** `SVG` 虽归类为图片类型，但不得调用图片预览 API，也不得进入灯箱导航集合
- **[当前契约]** 图片尺寸信息只能展示从已加载预览资源中可靠获得的真实值，不得估算
- **[当前契约]** 左右切换默认只遍历当前已加载图片集合，跨页切换需显式增量加载

### 视频播放

- **[项目约定]** 播放器优先使用 `Video.js`；HLS 优先走原生支持或 Video.js 内置播放能力
- **[当前契约]** 视频状态完全以后端 `status` 为准，前端不得自行推断“准备中”或“转码中”
- **[当前契约]** 清晰度、字幕和转码状态以后端返回为准
- **[当前契约]** 切换清晰度时尽量保持播放进度
- **[当前契约]** 字幕列表为空时隐藏字幕控件或展示“无字幕”，不得按错误处理

### 文档预览

- **[当前契约]** `Direct` 模式使用 `PDF.js` 或文本渲染
- **[当前契约]** `ThirdParty` 模式使用 `iframe` 承载第三方预览
- **[当前契约]** `NotAvailable` 模式展示“预览服务未配置，请下载后查看”并提供下载入口
- **[当前契约]** 第三方 Office 预览失败时提供“新窗口打开”和“下载”回退路径
- **[项目约定]** `PDF.js` 必须显式配置 worker 资源，不默认依赖 fake worker

## 交互、视觉与响应式规范

### 视觉与可访问性

- **[项目约定]** 默认采用暗色主题与 Glassmorphism 风格
- **[项目约定]** 文本与关键界面元素在暗色背景下应满足 `WCAG AA` 对比度目标；普通文本至少 `4.5:1`，大文本至少 `3:1`，关键图标和状态指示建议不低于 `3:1`
- **[项目约定]** 对非必要动画应尊重 `prefers-reduced-motion`
- **[项目约定]** Hover、展开、收起、淡入、淡出等过渡控制在 150ms - 300ms 范围内

### 响应式断点

- **[项目约定]** 统一断点为：
  - `desktop >= 1024px`
  - `tablet 768px - 1023px`
  - `mobile < 768px`
- **[项目约定]** 平板与移动端的图片、视频、文档预览统一全屏展示
- **[项目约定]** 移动端可将右键菜单退化为长按菜单

### 快捷键与焦点管理

- **[项目约定]** 任一模态打开后，仅允许对应模态作用域快捷键生效
- **[项目约定]** 输入框、下拉框、按钮、可编辑控件及带交互角色的宿主元素获得焦点时，必须禁用文件浏览器快捷键
- **[当前契约]** `Backspace` 仅在 `fileBrowser` 作用域且 `fileBrowserFocused = true` 时触发目录回退，并阻止浏览器历史后退
- **[当前契约]** 网络离线时顶部显示固定提示“网络连接已断开，请检查网络”

## 测试规范

- **[项目约定]** 至少覆盖单元测试、组件测试、属性测试、端到端测试四类测试层级
- **[项目约定]** 单元测试优先覆盖：文件名校验、排序/筛选函数、临时资源自动重试、核心 Store 状态流转、快捷键服务
- **[项目约定]** 组件测试优先覆盖：文件浏览、搜索、上传队列、云下载页面任务刷新、图片/视频/文档预览的加载态与错误态
- **[项目约定]** 属性测试优先覆盖稳定不变量，如文件夹优先排序、非法文件名拒绝、临时资源只自动重试一次、请求去重、已加载范围全选等
- **[当前契约]** E2E 需要覆盖：Cookie 有效/失效、登录引导、上传/下载/预览主路径、转码中视频、第三方预览失败与临时地址重试
