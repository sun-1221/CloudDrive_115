## 问题清单

### FQ-01 视频播放 DTO 字段与 integration 契约不一致

- **位置**：`.kiro/specs/115-cloud-drive-frontend/requirements.md:202`、`design.md:943-953`、`tasks.md:614`、`tasks.md:621`
- **后端依据**：`.kiro/specs/115-cloud-drive-integration/design.md:1231-1244`
- **维度**：Q4 覆盖、Q9 术语一致性、Q11 设计代码基线
- **严重级别**：🔴 高
- **差异说明**：frontend spec 声明前端类型由 OpenAPI 自动生成，但视频播放处要求消费 `availableDefinitions`、`videoUrls`、`userSelectedDefinition`，并定义 `VideoDefinition = 1 | 2 | 3 | 4 | 5 | 100`。integration 的 `CloudDriveVideoPlayDto` 当前定义为 `QualityOptions`、`AudioTracks`、`PlaybackSchemaStatus`、`Status` 等，并明确成功播放 schema 未采集前不得返回播放地址、清晰度或音轨。若按 frontend spec 实现，会写出基于幻影字段的前端逻辑。
- **建议修复**：frontend 改为严格消费 OpenAPI 生成字段，例如 `qualityOptions`（由后端 `QualityOptions` camelCase 生成）和 `playbackSchemaStatus`；若希望字段名为 `availableDefinitions/videoUrls`，应先修改 integration DTO 并重新生成 OpenAPI，不应在 frontend 单方面定义。

### FQ-02 用户空间 DTO 名称与 integration 契约不一致

- **位置**：`.kiro/specs/115-cloud-drive-frontend/requirements.md:330-331`、`design.md:1184-1214`、`tasks.md:775-779`
- **后端依据**：`.kiro/specs/115-cloud-drive-integration/requirements.md:442`、`design.md:773-775`
- **维度**：Q4 覆盖、Q9 术语一致性、Q11 设计代码基线
- **严重级别**：🟠 中高
- **差异说明**：frontend 使用 `CloudDriveStorageDetailsDto`，但 integration requirements/design 当前定义的是 `CloudDriveSpaceInfoDto { SchemaStatus = "not_collected" }`，`GetUserSpaceQuery` 返回的也是 `CloudDriveSpaceInfoDto`。前端如果以 OpenAPI 自动生成类型为准，将不存在 `CloudDriveStorageDetailsDto`。
- **建议修复**：将 frontend 的 `CloudDriveStorageDetailsDto` 全部改为 `CloudDriveSpaceInfoDto`；或反向统一 integration 命名，但必须保证 OpenAPI 类型只有一个权威名称。

### FQ-03 RecycleBinView 误用云下载自动刷新条件

- **位置**：`.kiro/specs/115-cloud-drive-frontend/design.md:368-369`
- **维度**：Q4 覆盖、Q9 术语一致性
- **严重级别**：🟡 中
- **差异说明**：回收站需求 R6 只要求列表查询、分页和清空回收站 202 job 轮询，没有“进行中任务”字段或 10 秒自动刷新规则。`RecycleBinView + RecycleItemCard` 设计却写成“仅在 itemSchemaStatus='available' 且存在进行中任务时 10 秒轮询”，这是云下载 R15 的规则被复制到回收站，会诱导实现者为回收站伪造任务状态判断。
- **建议修复**：删除该自动刷新行；回收站只在用户手动刷新、还原/彻底删除成功、清空回收站 job 完成后刷新。

## 新发现反思

- FQ-01 上轮漏检原因：上一轮关注“成功播放 schema 未采集”边界，未将前端手写 DTO 与 integration DTO 字段逐项对照。

## 修复计划

1. 将视频播放字段名与 integration/OpenAPI 统一：优先改 frontend 使用 `qualityOptions`，移除 `availableDefinitions/videoUrls/userSelectedDefinition` 幻影字段。
2. 将用户空间 DTO 统一为 `CloudDriveSpaceInfoDto`，或先在 integration 中完成命名变更后再同步前端。
3. 删除 RecycleBinView 的 10 秒“进行中任务”自动刷新规则，仅保留操作完成后的刷新。
