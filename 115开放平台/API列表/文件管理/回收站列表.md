# 回收站列表

<h3 id="Bhpmf">基本信息</h3>
**Path：** GET 域名 + /open/rb/list

**Method：** GET

**接口描述：回收站列表**

<h3 id="o2qxt">请求参数</h3>
**Headers**

| **参数名称** | **参数值** | **是否必须** | **示例** |
| --- | --- | --- | --- |
| Authorization | Bearer access_token | 是 | Bearer abcdefghijklmnopqrstuvwxyz  |

**Query**

| **参数名称** | **是否必须** | **示例** | **备注** |
| --- | --- | --- | --- |
| limit | 是 | 30 | 单页记录数，int，默认30，最大200 |
| offset | 是 | 0 | 数据显示偏移量 |
