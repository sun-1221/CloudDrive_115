# 开发者商业价值转化：推广产品得收益

<h1 id="Y9THX">一、简介</h1>
为助力开发者实现商业价值转化，与平台共同构建可持续发展的生态体系，115生活开放平台推出“**推广产品得收益**”计划。

本着“推广有奖、收益共享”的宗旨，开发者可通过集成平台提供的标准化服务接口，在应用场景中引导用户购买115增值服务，并基于用户实际购买的产品获取相应推广收益。

<h1 id="Oa8NC">二、服务形式说明</h1>
<h2 id="IYJIh">1.标准化服务接口</h2>
平台提供标准化服务接口体系，全面覆盖以下核心业务场景：

<h3 id="zIt1Y">1.1.VIP服务</h3>
**适用场景：**用户对应功能使用权限不足时提醒

**功能支持：**

• 视频播放权限升级：解决非VIP用户不支持在线预览视频、年费VIP以下用户不支持视频4K超轻转码等权限限制问题

• 大文件上传权限升级：解决月费VIP以下用户不支持上传115GB大文件等权限限制问题

**解决方案：**

• 引导用户升级至更高的VIP类型获取对应使用权限

<h3 id="JijjA">1.2.长期存储空间扩容服务</h3>
**适用场景：**用户云存储空间不足时提醒 

**功能支持：**

• 解决因空间容量不足导致的文件上传、复制及云下载添加失败等问题

**解决方案：  **

• 引导用户购买VIP服务获取更多长期存储空间

• 支持单独购买长期存储空间进行扩容

<h3 id="TXtPr">1.3.云下载配额</h3>
**适用场景：**用户云下载配额不足时提醒  

**功能支持：**

• 解决因服务配额不足导致的添加云下载失败等问题

**解决方案：  **

• 引导用户升级至更高的VIP类型获取更多云下载配额

• 支持单独购买云下载配额

<h2 id="JKwr4">2.收益获取模式</h2>
用户通过开发者应用场景引导进入购买页面，并成功购买以下任一服务产品，开发者即可获得对应推广收益：

• 115生活VIP服务(包括月费VIP、年费VIP等)

• 长期存储空间扩容

• 云下载配额

查看115生活开放平台的接口文档，详见下方的接入说明。

<h3 id="oByvI">获取产品列表地址</h3>
<h3 id="Bhpmf">基本信息</h3>
**Path**：GET 域名 + /open/vip/qr_url

**Method：** GET

**接口描述：**获取开放平台产品列表链接地址

<h3 id="o2qxt">请求参数</h3>
**Headers**

| **参数名称** | **参数值** | **是否必须** | **示例** |
| --- | --- | --- | --- |
| Authorization | Bearer access_token | 是 | Bearer abcdefghijklmnopqrstuvwxyz |

<h4 id="qsUPo">**Query**</h4>
| **参数名称** | **参数值** | **是否必须** | **示例** |
| --- | --- | --- | --- |
| default_product_id | 1 | 否 | 打开产品列表默认选中的产品对应的产品id，如果没有则使用默认的产品顺序。月费：5;  年费：1； 尝鲜1天：101 长期VIP(长期): 24072401 |
| open_device |  | 是 | 设备号 |
| hide_title | 0 | 否 | 是否隐藏购买页推荐人信息<br/>0：不隐藏（默认）<br/>1：隐藏 |

<h3 id="KP22x">返回数据</h3>
| **名称** | **类型** | **备注** |
| --- | --- | --- |
| state | boolean | 接口状态；true:正常；false：异常 |
| message | string | 异常信息 |
| code | string | 异常码  |
| data | object | 数据 |
| └─ qrcode_url | string | 开放平台产品列表地址 |

<h3 id="VXuyL">返回示例</h3>
```json
{
    "state": true,
    "message": "",
    "code": "0",
    "data": {
        "qrcode_url": "https://example.com/qr/123"
    }
}
```

<h2 id="tiYJL">3.场景触发与收益</h2>
接入成功后，以下场景将自动触发：

• 用户对应功能使用权限不足时，引导用户升级至更高的VIP类型；

• 用户云存储空间不足时，引导用户购买VIP服务或单独购买空间扩容套餐；

• 用户云下载配额不足时，引导用户升级至更高的VIP类型或单独购买云下载配额。

用户完成购买后，开发者即可获得对应的推广收益。
